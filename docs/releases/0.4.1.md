# Folio 0.4.1

Folio now supports local data entry by other agents, alongside a continuous 2K product introduction and simpler punctuation throughout the interface and demonstration content.

## Added

- A reusable `folio-data-entry` skill with an input reference, verification steps, and guidance for revision conflicts, partial success, and safe retries.
- A packaged `folio-cli.exe` with structured JSON commands for library inspection, schema discovery, validation, record creation and updates, and managed attachment imports.
- Coordinated desktop/CLI operations, revision-checked updates, and focus refresh that preserves unsaved drafts and rejects stale reads.
- A 60.6-second introduction at 2560 × 1440 and 30 fps. One continuous application session connects search, field editing, image/PDF preview, file management, appearance, and language changes. The README includes a consecutive 1080p animated excerpt.

## Downloads

- `Folio_0.4.1_x64-setup.exe`: Windows installer with the desktop app, CLI, skill, and license.
- `Folio_0.4.1_x64-portable.zip`: Extract the complete folder into a writable location. Keep its adjacent `data` folder when moving or updating an existing portable library.
- `folio-data-entry_0.4.1.zip`: The complete agent skill directory. Install it into the agent's skill directory or read `SKILL.md` directly; use the packaged CLI and the intended Folio data path.
- `folio-intro.mp4` and `folio-intro.en.vtt`: Full 2K introduction and English caption track.
- `SHA256SUMS.txt`: SHA-256 hashes for the release downloads.

The desktop application supports English and Simplified Chinese. Records, managed files, and previews remain local. The CLI starts no HTTP service. Data and backups are not encrypted, and this version does not change the storage format. Close Folio before replacing its executable, retain the existing `data` directory, and keep a backup of important records.

## Validation

The release passed 65 frontend unit tests, 58 browser/interface tests, and 47 Rust tests. A separate native WebView2 smoke test covers desktop/CLI coexistence, translated conflict recovery, native attachment refresh, image/PDF rendering, zoom, and page navigation. The skill was exercised independently with synthetic records and files. Film checks cover dimensions, frame count, sound, caption loading, playback, and seeking.

Before publication, tracked source and Git history were reviewed for credentials, private library content, unrelated documents, and media metadata. Demonstration records and attachments are synthetic. Private vaults, build caches, diagnostics, and test run directories remain excluded from Git and from the release package. Existing commit authorship is preserved.
