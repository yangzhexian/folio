# Folio 0.4.3

Folio now lets users customize their information collections while keeping records and files associated with stable category IDs. Independent image and PDF windows use the Windows title-bar close button without a duplicate internal control.

## Changes

- Open **Manage collections** beside the sidebar heading or in Settings. Edit the English and Chinese name, choose one of 24 icons, and add a collection.
- Reorder collections with the drag grip, its Up/Down keys, or the move buttons. The same order appears in the sidebar and record editor.
- New custom collections open a preselected blank record when choosing **New**. Record labels, template icons, and bilingual search use the saved definitions.
- Store the catalog in the local SQLite library and include it in backups. Names and icons can change without moving records or renaming existing files.
- Validate nonempty, unique names in each language, with a limit of 60 characters per name and 100 collections. Unsaved edits can be discarded; conflicting catalog saves preserve the draft and require reopening the latest definitions.
- Expose `categories` and a version-3 CLI schema so agents can discover exact category IDs before entering data. Record writes reject unregistered category IDs. The data-entry skill includes the updated workflow.
- Remove the duplicate Close button from native PNG/JPEG/PDF previews, including loading, error, and empty states. The title-bar close, minimize/maximize, resize, pinning, zoom, attachment switching, and PDF page navigation remain available. Browser previews retain their internal Close button.

## Compatibility

Existing libraries open with the original nine collection definitions. The initial definitions are read without rewriting legacy rows, and read-only CLI discovery does not initialize an empty library. Existing collections cannot be deleted in this version.

An unchanged default catalog continues to export a version-1 backup. Customized definitions or ordering export version 2, which requires Folio 0.4.3 or later to restore. This version reads both formats, validates category references before replacing the active library, and assigns a fresh catalog revision after restore. Source files and prior recovery copies remain intact.

## Packages

- `Folio_0.4.3_x64-setup.exe`: Windows installer with Folio, the local backend CLI, agent skill, and license.
- `Folio_0.4.3_x64-portable.zip`: Complete portable folder. Retain the existing adjacent `data` directory when updating.
- `folio-data-entry_0.4.3.zip`: Updated agent instructions and CLI reference.
- `SHA256SUMS_0.4.3.txt`: Package checksums.

Close Folio before replacing its executable. All library operations and attachment processing remain local.

Tests used isolated synthetic libraries, and the Windows installer was built and inspected without installing over an existing personal library.
