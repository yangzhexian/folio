# Folio 0.4.4

The desktop app and its Remotion introduction now use the same Folio wordmark. The one-minute film follows a continuous session through bilingual field search, drag-and-drop editing and import, a pinned attachment preview, PDF paging and collection organization.

## Changes

- The film displays a chapter icon and sentence-case label in the upper right. English and Chinese subtitles occupy two centered lines. The README includes the full 1080p GIF and links to the 2560 × 1440 video.
- The main window and the attachment viewer share controls and theme tokens. Search reuses index data across views. The CLI uses record-scoped queries for individual reads and indexed counts for summaries.
- PDF previews load the original bundled PDF.js worker locally. Backup export validates the destination before replacing a file.
- Contributors can follow the repository maintenance SOP and the new `folio-development` skill for UI changes, storage compatibility and verification. Desktop users and automation tools retain the dedicated `folio-data-entry` skill.

## Upgrading

Existing records, category definitions and managed attachments keep their IDs, order and paths. The CLI continues to use schema 3. Folio reads both backup formats and writes version 1 for default collections or version 2 for customized collections. Close Folio before replacing the portable executables and keep the existing adjacent `data` folder.
