# Working on Folio

Start with the user action and the entry point that owns it. Use the [maintenance SOP](docs/development/README.md) to select implementation and verification steps. The [development skill](skills/folio-development/SKILL.md) is an alternative entry into the same workflow. For recording information in a local vault, use the separate [data-entry skill](skills/folio-data-entry/SKILL.md).

Use English for source, developer documentation and Conventional Commit subjects. Ship English and Chinese UI text together. Keep each independently verified change in a focused commit.

Keep each prose paragraph on one physical line in Markdown, LaTeX and other text sources. Keep inline math and its surrounding prose on that line, with a space on each side of the formula. Preserve structural newlines for headings, lists, tables, code, display math and paragraphs. Do not insert markup solely to wrap source lines.
